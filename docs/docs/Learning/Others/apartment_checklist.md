## Structure

- [ ] No cracks, damp marks, uneven walls, bad wall painting
- [ ] Windows open and close, and are sealed (no wind when closed)
- [ ] Doors open and close without scratch or noise
- [ ] Floor is even, no lose tiles, no cracks
- [ ] Check if painting is done properly and double layer
- [ ] Kitchen cabinets are aligned, decent quality, open and close
- [ ] Balcony railings are stable and not rusty

## Plumbing

- [ ] All taps work and have normal pressure
- [ ] Check leaks or moisture under sink (kitchen, bathroom)
- [ ] Check damp marks on corners of walls, ceiling, and floor
- [ ] Check leakage in shower, bathtub, toilet, and washing machine
- [ ] Check leaks in heating radiators

## Electrical

- [ ] Check all light switches work
- [ ] Check all power sockets work
- [ ] Check for exposed wides
- [ ] Check circuit breaker box is well installed 

## Hygiene & Sanitation

- [ ] Check for signs of bugs
- [ ] Check for signs of bed bugs
- [ ] Check if there walls and floors are clean (no stains, mold, oils)

- [ ] Check path to garbage disposal is normal

## Facilities

- [ ] Nearby stores, nearby gym, public transport
