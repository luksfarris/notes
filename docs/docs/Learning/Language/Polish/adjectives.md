## Adjective Comparative and Superlative Forms

Examples:

| Adjective | Translation | Comparative | Superlative    |
| --------- | ----------- | ----------- | -------------- |
| niski     | Short       | niższy      | najniższy      |
| długi     | Long        | dłuższy     | najdłuższy     |
| gruby     | Fat         | grubszy     | najgrubszy     |
| stary     | Old         | starszy     | najstarszy     |
| brudny    | Dirty       | brudniejszy | najbrudniejszy |


Cases:

| Case          | Adjective      | Comparative          | Superlative             |
| ------------- | -------------- | -------------------- | ----------------------- |
| Regular       | gruby (-szy)   | grubszy              | najgrubszy              |
|               | modny (-ejszy) | modniejszy           | najmodniejszy           |
| Alternacje    | miły (ł -> l)  | milszy               | najmilszy               |
|               | długi (g -> ż) | dłuższy              | najdłuższy              |
|               | tani (n -> ń)  | tańszy               | najtańszy               |
|               | wąski (s -> ż) | węższy               | najwęższy               |
| Redukcja      | krótki (-ki)   | krótszy              | najkrótszy              |
|               | szeroki (-oki) | szerszy              | najszerszy              |
|               | daleki (-eki)  | dalszy               | najdalszy               |
| Nieregularnie | duży           | większy              | największy              |
|               | mały           | mniejszy             | najmniejszy             |
|               | dobry          | lepszy               | najlepszy               |
|               | zły            | gorszy               | najgorszy               |
| Opisowo       | (adjective)    | bardziej (adjective) | najbardziej (adjective) |
|               | kolorowy       | bardziej kolorowy    | najbardziej kolorowy    |
