# Declensions (Cases)

Remember that Polish, just like other Slavic languages, don't have articles, so the function of the article is fulfilled by modifying nouns, adjectives, and pronouns (like Latin).

Nouns and adjectives are inflected for **seven cases**, but also for gender (M/F/N) and number (S/P). The cases are:
- nominative
- vocative
- accusative
- genitive
- instrumental
- dative
- locative

There are four types of noun and adjective declension based mostly on gender:

- a-stems: most of them are feminine, but if they refer to a male are masculine.
- masculine o-stem
- neuter o-stem
- i-stem: includes feminine nouns.

## M: Mianownik (Nominative) - Kto/co jest?

Mianować is to name, to nominate, to call.

- Who what **exists**? If I can substitute the verb with the verb to exist, then the noun is nominative.
- Kto jest? Rycerz jest.
- Co jest? Miecz jest.


|           | Singular Noun       | Plural Noun                  |
| --------- | ------------------- | ---------------------------- |
| Masculine | -∅ / -a             | -i / -y / -e / -owie / -anie |
| Feminine  | -a / -i / -∅        | -i / -y / -e                 |
| Neuter    | -o / -e /  -ę / -um | -a                           |

## D: Dopełniacz (Genitive) - Kogo/czego nie ma?

Dopełniacz: what can I fill, complete, complement.

:::tip
"do"-pełniacz, think about the "do" word, and apply it when you see it.

- Dziś nie idę *do* [...]
- Moja ciotka często chodzi *do* [...]
- dlatego też często chodzę *do* [...]
:::

- Who/what **does not exist**? If I can substitute the verb with the verb to not exist, then the noun is genitive.
- Kogo nie ma? Rycerza nie ma.
- Czego nie ma? Miecza nie ma.

|           | Singular | Plural             |
| --------- | -------- | ------------------ |
| Masculine | -u / -a  | -ów / -y / -i      |
| Feminine  | -y / -i  | -∅ / -y / -i       |
| Neuter    | -a       | -∅ / -y / -i / -ów |


## C: Celownik (Dative) - Komu/czemu daję?

Cel = objective, goal.

- To whom/what do I **give**? If I can substitute the verb with the verb to give, then the noun is dative.
- Komu daję? Rycerzowi daję.
- Czemu się przyglądam? Mieczowi się przyglądam. (what do I observe? I observe the sword)

|           | Singular      | Plural |
| --------- | ------------- | ------ |
| Masculine | -owi / -u     | -om    |
| Feminine  | -'e / -y / -i | -om    |
| Neuter    | -u            | -om    |

## B: Biernik (Acusative) - Kogo/co widzę?

Bierny is passive, inactive, not doing anything.

- Who do I **see**? If I can substitute the verb with the verb to see, then the noun is accusative.
- Kogo widzę? Widzę rycerza
- Co widzę? Widzę miecz.


|           | Singular    | Plural      |
| --------- | ----------- | ----------- |
| Masculine | -∅          | Nominative! |
|           | -a          | Genitive!   |
| Feminine  | -ę / -∅     | Nominative! |
| Neuter    | Nominative! | Nominative! |

## N: Narzędnik (Instrumental) - Z kim/czym jestem?

- With whom/what am I? If I can substitute the verb with the verb to be, then the noun is instrumental.
- Z kim jestem? Jestem z rycerzem.
- Z czym jestem? Jestem z mieczem.


|           | Singular   | Plural     |
| --------- | ---------- | ---------- |
| Masculine | -em / -iem | -ami / -mi |
| Feminine  | -ą         | -ami / -mi |
| Neuter    | -em / -iem | -ami / -mi |

## M: Miejscownik (Locative) - O kim/czym myślę?

Miejsce is a place, a location.

- What am I **thinking** about? If I can substitute the verb with the verb to think, then the noun is locative.
- O kim myślę? Myślę o rycerzu.
- O czym myślę? Myślę o mieczu.

| --------- | -------- | ------ |
| Masculine | -'e / -u | -ach   |
| Feminine  | Dative!  | -ach   |
| Neuter    | -'e / -u | -ach   |
