# Aspekt dokonany / niedokonany

Polish verbs change depending on the aspect of the action. There are two aspects: **niedokonany** (imperfective form) and **dokonany** (perfective form).

:::info[Etymology]
Dokonany means accomplished.
:::

**Niedokonany**, when we did something for a duration of time, or repeatedly:
  - Kiedy mówimy o tym, **jak długo** coś robiliśmy.
  - Kiedy mówimy o tym, **jak często**, ile razy coś robiliśmy.

**Dokonany**, when we did something to completion or once:
  - Kiedy mówimy o tym, że zrobiliśmy coś **do końca**.
  - Kiedy mówimy o tym, że zrobiliśmy coś **jeden raz**.


### Verb alterations

There are 4 main types of verb modifications (this is not official, just a way to remember them):
- Case 1: cases where a prefix is added to the verb (robić -> zrobić)
  - careful, different suffixes can change the meaning of the verb
- Case 2: cases where the middle is slightly changed (opowiadać -> opowiedzieć)
- Case 3: cases where the ending is shortened (kupować -> kupić)
- Case 4: cases where the verb is completely different (mówić -> powiedzieć)


### Keywords to determine the aspect of the verb:

| Niedokonany                        | dokonany            |
| ---------------------------------- | ------------------- |
| codziennie (daily)                 | nareszcie (finally) |
| często (often)                     | nagle (suddenly)    |
| rzadko (rarely)                    | w końcu (finally)   |
| od czasu do czasu (sometimes)      | jeden raz (once)    |
| czasem (often)                     | lubić (to like)     |
| zaczynać (started)                 | zacząć              |
| kończyć (finish)                   | skończyć            |
| długo (for a long period)          |                     |
| krótko (for a short period)        |                     |
| od siódmej do ósmej (from 7 to 8)  |                     |
| (przez) dwie godziny (for 2 hours) |                     |
| kilka (several) razy               |                     |
| kilkanaście (a dozen) razy         |                     |
| zawsze (always)                    |                     |
| zwykle (usually)                   |                     |


## Case 1 (Prefixes) Examples

| Niedokonany | Dokonany    | Variation |
| ----------- | ----------- | --------- |
| pisać       | napisać     | na-       |
| czytać      | przeczytać  | prze-     |
| robić       | zrobić      | z-        |
| rozmawiać   | porozmawiać | po-       |
| szukać      | poszukać    | po-       |
| słuchać     | posłuchać   | po-       |
| pytać       | zapytać     | za-       |
| czekać      | poczekać    | po-       |
| myśleć      | pomyśleć    | po-       |
| jechać      | pojechać    | po-       |
| iść         | pójść       | po-       |
| pił         | wypił       | wy-       |


## Case 2 (Middle) Examples

:::tip
Usually this is for verbs that look like they already have a prefix
:::

| Niedokonany | Dokonany     | Variation         |
| ----------- | ------------ | ----------------- |
| opowiadać   | opowiedzieć  | -wia- > -wiedzie- |
| odpowiadać  | odpowiedzieć | -wia- > -wiedzie- |
| powtarzać   | powtórzyć    | -ta- > -tó-       |
| otwierać    | otworzyć     | -wiera- > -worzy- |
| zamykać     | zamknąć      | -myka- > -mkną-   |
| zapominać   | zapomnieć    | -mina- > -mnie-   |
| wracać      | wrócić       | -raca- > -róci-   |


## Case 3 (Ending is shortened) Examples

| Niedokonany | Dokonany | Variation     |
| ----------- | -------- | ------------- |
| kupować     | kupić    | -ować > -ić   |
| dostawać    | dostać   | -awać > -ać   |
| dawać       | dać      | -awać > -ać   |
| wstawać     | wstać    | -awać > -ać   |
| wybierać    | wybrać   | -ierać > -rać |


## Case 4 (Completely different) Examples

| Niedokonany | Dokonany   |
| ----------- | ---------- |
| mówić       | powiedzieć |
| brać        | wziąć      |
| oglądać     | obejrzeć   |
| widzieć     | zobaczyć   |
