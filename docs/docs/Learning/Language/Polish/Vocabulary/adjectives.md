## Comparisons

Dla stopnia wyższego:
- Niż -> Mianownik
- Od -> Dopełniacz

- Skuter jeżdzi wolniej (niż samochód) / (od samochodu)
- Letni dzień jest dłuższy niż noc

Dla stopnia najwyższego
- z(e) -> Dopełniacz
- W -> Miejscownik

- To zebranie było najczykawsze ze wszystkich.
- Dotota jest najmądrzejsza w zespole.
