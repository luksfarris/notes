# Nouns From Verbs (Rzeczownik Odczasownikowy)

In English there's the same concept with -ing, for instance (to miss)->(missing).

In Polish there are four general cases:

| #   | Verb Ending     | Noun Ending | Example               |
| --- | --------------- | ----------- | --------------------- |
| 1   | -ać, -ować, -eć | -nie        | pisać -> pisanie      |
| 2   | -ić, -yć,       | -enie       | robić -> robienie     |
| 3   | short verbs     | -cie        | myć -> mycie          |
| 4   | -ąć             | -ęcie       | zamknąć -> zamknięcie |

## Examples

Case 1 Verbs:

- ać: pływać, czytać, słuchać, śpiewać
- ować: pracować, malować, gotować
- eć: rozumieć, pachnieć

Case 2 Verbs:

- ić: robić, mówić, lubić
- yć: uczyć, tańczyć, chodzić

Case 3 Verbs:

- short verbs: myć, pić, być, wejść, wyjść

Case 4 Verbs:

- ąć: zamknąć


Exceptions
- jeść -> jedzenie
- pracować -> praca (although pracowanie is also possible)
